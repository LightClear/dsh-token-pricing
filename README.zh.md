# dsh-client-token-pricing

[English](README.md) | 中文

Web 界面的按提供方/模型 token 定价：一个持久化的 `token-pricing` 设置段（每百万 token 的美元价格：未命中输入、缓存命中输入、输出，以及可选的高峰时段及其独立价格档），以及在 `conversation.composer.dock` 数据栏中、随出厂统计行并列显示的会话费用读数。node 半身只注册设置命名空间，其余全部复用现有 Host 服务。

读数显示 `模型 · 输入 $X · 输出 $Y · 总计 $Z`：按会话当前提供方/模型路由（`session.models`）匹配到的定价条目，计算会话累计 `tokenUsage` 投影的费用。路由没有对应配置、或尚无任何用量时不显示。启用高峰定价后，当前档位（`高峰价` / `非高峰价`）按配置时区下的当前时间选择，每分钟刷新一次；悬停提示按未命中/命中 token 与单价给出明细。

设置页（"模型定价"）沿用模型设置页的布局：来自 `llm.models` 目录的每个提供方一张卡片，卡片内列出各模型（已配置/未配置状态点）与编辑器（三档基础价 + 高峰价格档）。已存条目所属的提供方不在目录中时仍会渲染（标记"未发现于目录"），保证可继续编辑。「保存配置」通过设置作用域（`settingsScope`）整体写入条目列表，其恢复读会把表单与 Host 真相重新对齐；被拒绝的写入会显示保存失败。

`/client` 导出为插件主体（`apply`/`inject`）、dock 与设置页组件及其注入面类型。纯费用计算位于 `src/client/pricing.ts`。

## 模型体验

无：本插件不增加任何提示内容，不注册任何模型可见工具，也不把任何设置读入请求路径。读数只是对既有持久数据的呈现（`tokenUsage` 投影与 `session.models` 路由），不会改变模型看到的内容。

#### KV 缓存影响

无。插件仅在请求提交后读取 `tokenUsage` 投影；不影响请求组成、缓存复用或压缩。

## 已知限制与待办

- **按当前价格计费的整会话总额** — 读数以当前匹配条目与当前时间计价会话累计 token；早期模型或早期价格档产生的用量不会按请求回溯重算，因此该数字是按今日价格的估算，而非逐请求账单。
- **高峰档仅显示时生效** — 档位在渲染时选择；时间跨过高峰边界时，累计总额不会回溯拆分。
